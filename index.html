Prinsip dan perhitungan

1) Prinsip dasar

Prinsip dasar AAS (Atomic Absorption Spectrophotometer) adalah penyerapan radiasi oleh atom-atom bebas unsur dalam keadaan dasar (ground state) pada panjang gelombang yang khas untuk unsur tersebut. Banyaknya radiasi yang diserap sebanding dengan konsentrasi atom dalam sampel, sesuai Hukum Lambert–Beer.

A = log(I₀/Iₜ) = ε · b · C

2) Prinsip pengujian logam Cu

Kadar ion logam Cu dalam air limbah ditetapkan menggunakan spektrofotometer serapan atom (SSA) nyala. Larutan standar dan sampel yang telah disaring diaspirasikan ke alat SSA hingga terkabutkan oleh nebulizer, lalu dibakar dengan nyala api sehingga senyawaan organik terbakar dan ion-ion logam teratomisasi. Atom logam tersebut menyerap radiasi resonansi dari lampu katoda, dan besarnya radiasi yang diserap sebanding dengan konsentrasi logam dalam sampel.

3) Preparasi Cu total

Sampel sebanyak 50 mL dipipet ke dalam gelas piala 100 mL, ditambah 5 mL HNO₃ pekat, lalu dipanaskan hingga volume 15–20 mL. Setelah didinginkan, larutan dipindahkan ke dalam labu ukur 50 mL dan ditera dengan akuades. Larutan yang diperoleh kemudian diaspirasikan ke dalam alat AAS untuk diukur.

4) Preparasi Cu terlarut

Sampel disaring menggunakan kertas saring Whatman Grade 42, kemudian dipipet sebanyak 50 mL ke dalam gelas piala 100 mL. Selanjutnya ditambahkan 5 mL HNO₃ pekat dan dipanaskan hingga volume larutan tersisa 15–20 mL. Larutan didinginkan, kemudian dimasukkan ke dalam labu ukur 50 mL dan ditera dengan akuades. Setelah itu, larutan dipipet sebanyak 5 mL ke dalam labu ukur 50 mL dan ditera dengan HNO₃ 0,05 M. Larutan yang diperoleh kemudian diaspirasikan ke dalam alat AAS untuk diukur.

5) Rumus perhitungan

Kurva kalibrasi (regresi linear deret standar)

y = a + b·x   (y = absorbansi, x = konsentrasi standar)

Konsentrasi dan kadar Cu

C = (A − a) / b
C terkoreksi = C − Cblanko  (hanya bila Cblanko > C standar kedua / 10; selain itu C terkoreksi = C)
Kadar Cu = C terkoreksi × FP

Presisi

%RPD = |x₁ − x₂| / x̄ × 100%  (2 ulangan)
SD = √[Σ(xᵢ − x̄)² / (n − 1)] ;  %RSD = SD / x̄ × 100%  (≥ 3 ulangan)

Akurasi (spike)

C2 = Cstandar × Vstandar / Vlabu takar
C3 = C terkoreksi (sampel + spike) × FP
%Recovery = (C3 − C1) / C2 × 100%

6) Catatan

  • A = absorbansi; a = intersep; b = slope; C = konsentrasi terbaca dari kurva (mg/L); FP = faktor pengenceran.
  • C1 = rerata kadar Cu total; C2 = konsentrasi spike yang ditambahkan; C3 = kadar Cu sampel + spike. Aturan koreksi blanko untuk C3 sama dengan Cu total.
  • Koreksi blanko hanya diterapkan bila konsentrasi blanko melebihi sepersepuluh konsentrasi standar kedua; bila tidak, blanko dianggap tidak berkontribusi berarti.
  • Pada preparasi Cu terlarut, pengenceran 5 mL menjadi 50 mL memberikan FP = 50 / 5 = 10.
  • Syarat keberterimaan: koefisien korelasi r ≥ 0,995 (SNI 6989.6:2009); %RPD atau %RSD di bawah batas presisi yang ditetapkan; %Recovery 85–115%.

Ringkasan hasil

Syarat keberterimaan: r ≥ 0,995 (SNI 6989.6:2009); %RPD/%RSD di bawah batas presisi; %Recovery 85–115%. Koreksi blanko hanya diterapkan bila konsentrasi blanko melebihi sepersepuluh konsentrasi standar kedua.
